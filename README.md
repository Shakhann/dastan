## 🤖 Жасанды интеллект (AI) қолданылуы

AI екі бөлікте қолданылды:

1. **TTS дауыс генерациясы** — `edge-tts` (Microsoft Edge Text-to-Speech) арқылы барлық сөздер, мақалдар, жаңылтпаштар және Wikipedia мәтіндерінің басты бөлігі алдын ала MP3-ке жазылды (kk-KZ-AigulNeural дауысы). Бұл қазақ тілін табиғи, акцентсіз айтуға мүмкіндік береді.

2. **Код жазуға көмек** — жоба архитектурасын жоспарлауға, CSS/JS код жазуға, контентті құрастыруға AI көмегі пайдаланылды.

**speak() функциясының логикасы:**
1. Алдымен `audio/manifest.json`-нан дайын MP3 іздейді → табады болса, оны ойнатады (ең сапалы қазақша дауыс)
2. MP3 табылмаса → Web Speech API (`kk-KZ`) қолданады
3. Қазақ дауысы жоқ браузерде → орыс транскрипциясымен fallback (ә→е, қ→г, ғ→г, ң→нг, ө→о, ұ→у, ү→ы, і→и)

## 📄 Контент дереккөздері

Барлық мәдени контент **Қазақ Уикипедиясынан** (kk.wikipedia.org) MediaWiki API арқылы алынды:
- Лицензия: **CC BY-SA 4.0**
- Әр мәтінде `source_url` (түпнұсқа сілтеме) және `license` белгісі міндетті түрде көрсетілген
- Табылмаған беттер (5 тақырып) қолмен толықтырылды (override нұсқа)

### Файл құрылымы:
```
/data/
  jyr/        — жыр-дастандар (5 файл)
  tarikh/     — тарих (4 файл)
  taam/       — тағамдар (5 файл)
  kijim/      — киімдер (2 файл)
  tulgalar/   — тұлғалар (3 файл)
  oyu/        — ою-өрнек (1 файл)
```

Әр JSON: `{id, title, category, text, source_name, source_url, license, fetched_at}`

## 🔧 Технологиялар

- **Таза HTML + CSS + JavaScript** — фреймворксыз, жеңіл, жылдам
- **GitHub Pages** — тұрақты интернет URL (localhost емес)
- **edge-tts** (Python) — TTS дауыс генерация
- **MediaWiki API** — Wikipedia контент алу
- **Web Speech API** — браузер ішіндегі дауыс + микрофон танымалдылық
- **localStorage** — прогресс сақтау (серверсіз)
- **SVG** — ою-өрнектер + иконкалар (суретсіз)

## 🚀 Іске қосу және жариялау

### Жергілікті:
```bash
cd dastan
```

```
dastan/

    views_a.js        — home, dict, grammar
    views_b.js        — read, voice, quiz, proverbs

  content_topics.json — тақырыптар тізімі
```
