# ДАСТАН — қазақ тілі және мәдениеті веб-платформасы

«Қазақ тілін қолдануға арналған IT өнімдер» облыстық байқауына арналған интерактивті, 11 модульді веб-платформа.

## 🤖 Жасанды интеллект (AI) қолданылуы

AI екі бөлікте қолданылды:

1. **TTS дауыс генерациясы** — `edge-tts` арқылы бұрын жасалған MP3 жазбалар бар. Оқу мазмұны жаңартылғаннан кейін мақалдар, жаңылтпаштар, грамматика және әдеби мәтіндер ағымдағы мәтіннен браузердің сөйлеу қызметімен дыбысталады. Ескі жазбалар жаңа мәтіннің орнына ойнатылмайды; аудио файлдары мен манифест өзгертілмеді.

2. **Код жазуға көмек** — жоба архитектурасын жоспарлауға, CSS/JS код жазуға, контентті құрастыруға AI көмегі пайдаланылды.

**speak() функциясының логикасы:**
1. Алдымен `audio/manifest.json`-нан дайын MP3 іздейді → табады болса, оны ойнатады (ең сапалы қазақша дауыс)
2. MP3 табылмаса → Web Speech API (`kk-KZ`) қолданады
3. Қазақ дауысы жоқ браузерде → орыс транскрипциясымен fallback (ә→е, қ→г, ғ→г, ң→нг, ө→о, ұ→у, ү→ы, і→и)

## 📄 Контент дереккөздері

Мақалалар екі түрлі дерекпен берілген:
- **11 редакциялық түйіндеме** — зерттеу жинағының 6-бөлімінен бейімделген. `source_name`: «ДАСТАН редакциясы»; `source_url`: жинақтағы дереккөз. Жеке ашық лицензия берілмеген; олар Уикипедияның төл мәтіні ретінде көрсетілмейді.
- **Қобыланды туралы редакциялық бейімдеу** — бастапқы Уикипедия мақаласынан жырға қатысты үзінділер ғана қалдырылды; дереккөз сақталып, CC BY-SA 4.0 көрсетілді.
- **9 сақталған Уикипедия үзіндісі** — әр файлдағы дереккөз бен CC BY-SA 4.0 белгісі сақталған; аудитте аталған мәтін ақаулары түзетілген.

Статикалық оқу мәтіндері зерттеу жинағының 1–5-бөлімдерінен алынды: 5 грамматика сабағы, 30 тест сұрағы, 12 мақал, 9 жаңылтпаш, 8 ою атауы. Сөздіктегі 30 сөз сақталды, 6 мысал түзетілді.

Редакциялық іріктеу: шұбаттың ауруларды емдейтіні туралы мәлімдеме, Ботай туралы «әлемде алғаш» және қымыз ашыту туралы кесімді тұжырым, «жанат ішік» ешкі терісінен жасалады деген жіктеу және Абайдың Отыз сегізінші сөзіне телінген өлең тіркесі алынды. Үндестік бөліміндегі «Жан+пейіс → Жампейіс» тоғыспалы ықпалға мысал ретінде қолданылмады. Грамматика кестелері интерфейстегі ереже мен мысал пішіміне ықшамдалды. Қазы дайындау мәтінінде ішекке салынатыны «қабырға еті» деп нақтыланды.

Сақталған 8 SVG дәстүрлі атаулардың дәл пішініне сәйкес келмейді: Қошқармүйіз, Сыңармүйіз, Қырықмүйіз, Түйетабан, Құсқанаты, Ботакөз, Тұмарша, Ирек. Бетте ескерту берілген; қате пішіндерді үйрететін сәйкестендіру ойыны алынды.

## 🔧 Технологиялар

- **Таза HTML + CSS + JavaScript** — фреймворксыз, жеңіл, жылдам
- **GitHub Pages** — тұрақты интернет URL (localhost емес)
- **edge-tts** (Python) — TTS дауыс генерация
- **MediaWiki API** — Wikipedia контент алу
- **Web Speech API** — браузер ішіндегі дауыс + микрофон танымалдылық
- **localStorage** — прогресс сақтау (серверсіз)
- **SVG** — ою-өрнектер + иконкалар (суретсіз)

## 🚀 Іске қосу және жариялау

### Жергілікті:
```bash
cd dastan
python3 -m http.server 8792
# http://localhost:8792
```

### Контент жаңарту:
```bash
python3 fetch_content.py          # тек қорғалмаған Wikipedia тақырыптарын жүктеу
python3 generate_audio.py         # MP3 дауыс қайта жасау
```

`content_topics.json` ішіндегі `source: "editorial"` немесе `preserve_local: true` тақырыптары автоматты жүктелмейді. Қазіргі 21 мақала жергілікті түзетулерді сақтау үшін қорғалған. Скрипт бар файлдағы `source_name: "ДАСТАН редакциясы"` белгісін де тексереді және оны сақтаудың алдында қайта қорғайды. Жаңа Wikipedia тақырыбын қосқанда ғана қорғалмаған жазба жасаңыз. `fetch_log.txt` қолданылмайды; хабарламалар консольге шығады.
